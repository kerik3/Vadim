# Собери всех Вадимов

Готовый подарок на 18-летие: 19 фотографий, альбом, билеты и 18 заданий. HTML, CSS и JavaScript без сборки и внешних библиотек.

## Разместить на GitHub Pages

1. Распакуй архив. Создай на GitHub новый репозиторий, например `vadim18` (для бесплатного GitHub Pages — Public).
2. Нажми **Add file → Upload files** и перетащи **содержимое папки сайта**: `index.html`, `album.html`, `games.html`, файлы `.js`, `style.css` и папку `assets`. `index.html` должен оказаться в корне репозитория, а не во вложенной папке. Нажми **Commit changes**.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Source → Deploy from a branch**, ветку **main** и папку **/(root)**. Нажми **Save**.
5. После завершения публикации ссылка появится в этом же разделе. Обычно адрес имеет вид `https://ТВОЙ-ЛОГИН.github.io/vadim18/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Сайт сейчас подготовлен локально, но ещё не опубликован. При размещении фотографии входят в сайт и доступны его посетителям.

## Как играть

- Первый билет выдаётся сразу.
- Через пять минут на главной становится доступна кнопка получения бесплатного билета. Таймер сохраняется при закрытии страницы. Следующий отсчёт начинается после получения билета: одновременно ждёт один бесплатный билет.
- Открытие тратит один билет и сразу сохраняет выпавшую фотографию в альбом.
- У всех 19 фотографий одинаковый шанс выпадения. Метка «особенный» — оформление, а не пониженная вероятность.
- За три повторные фотографии можно получить билет. После трёх повторов подряд следующее открытие гарантирует новую фотографию, пока коллекция не собрана.
- За первое прохождение каждого задания — один билет. Повторять игры можно, но награда не повторяется.
- «Не нажимать» показывает отдельную фотографию на весь экран и даёт один билет. Срабатывает один раз. Изображение можно закрыть кнопкой или Escape; оно также закроется само. Звука и мигающих вспышек нет.
- После сбора всего альбома открывается поздравление.

## Игры

- Шахматы: 5 настоящих задач Lichess с рейтингами 1476–1575, с ответными ходами соперника. Принимается основная линия решения из базы.
- Маршрут коня: собрать три подарка и прийти на h8 за 8 ходов.
- Баскетбол: 5 площадок с разными стартами и кольцами; нужен отскок от боковой стены. Управление углом и силой.
- Химия: 3 задачи с переливанием и отменой хода, 3 задачи на коэффициенты химических уравнений.
- Найди пару: одна игра на 6 пар фотографий.

Итого 18 заданий + одноразовая кнопка = 19 наград. В переписке первоначально была арифметическая ошибка; состав игр полностью сохранён.

## Прогресс

Альбом, билеты, завершённые задания и таймер сохраняются в браузере на устройстве игрока. На другом устройстве или после очистки данных браузера начнётся новая игра. На локальном просмотре и на GitHub Pages сохранения разные: тестовое прохождение не переносится в опубликованный подарок.

Сайт рассчитан на личное поздравление: серверной защиты от изменения сохранения и часов устройства нет.

## Что можно поменять

- `assets/vadim-01.jpg` … `vadim-19.jpg` — фотографии коллекции. Можно заменить файл, сохранив имя.
- `assets/surprise.jpg` — отдельное фото для скримера.
- `core.js`: списки `names` и `captions` содержат названия карточек и подписи в том же порядке, что и фотографии.
- `home.js`: функция `showFinal()` в конце содержит текст финального поздравления.
- `style.css` — цвета и оформление.

Один точный дубликат из исходного архива исключён; оставлены 19 уникальных снимков.

## Локальный просмотр

Надёжнее открывать сайт через локальный сервер, чтобы все три страницы использовали одно сохранение. Открой терминал в этой папке и выполни:

```sh
python3 -m http.server 8000
```

Затем открой http://localhost:8000. Для остановки нажми Ctrl+C. При открытии `index.html` двойным щелчком отдельные браузеры могут ограничивать или разделять сохранения между страницами.
